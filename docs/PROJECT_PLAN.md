## 1. 背景与目标

用户有四/六级资料，但距离考试时间有限，不可能全部背完；而且不同用户的目标日期不同，不能把计划写死在某个考试日。项目要解决的不是“资料不够”，而是**在有限时间里把高频内容变成每天能执行、能检测、能坚持的任务**。

### 1.1 总目标

> 让用户选择四级或六级、设定自己的目标学习日期，系统把最高频的作文/翻译表达、196 个高频词、听力/阅读/写译题型分配到每一天，并且让进度**不会因为换浏览器、清缓存或误操作而丢失**。

### 1.2 用户目标（按优先级）

1. **能过**：优先拿分性价比最高的作文模板、翻译句型、高频词。
2. **每天知道做什么**：打开就有“今日任务”，不用自己排计划。
3. **能检测**：背完能测，写译能用键盘作答，而不是只看。
4. **数据不丢**：本地保存 + 可选云端 + 可导出。
5. **随时能打开**：双击 HTML 可用；也可以启动服务端；还可以发单文件给别人。

### 1.3 非目标

- 不做完整真题库（PDF 没有原卷，现有练习为仿真）。
- 不做 OCR 笔迹识别（词汇打字检测自动比对答案）。
- 不做多用户账号/权限系统（同步码即身份）。
- 不做前端框架重构（保持无构建、可双击打开）。

## 2. 用户与使用场景

| 场景 | 行为 | 成功标准 |
| --- | --- | --- |
| 每天早上 | 打开「全套 → 今日」，看新词/复习/练习任务 | 30 秒内知道今天做什么 |
| 通勤/碎片时间 | 手机浏览器打开同一目录或单文件，背 10 个词 | 390px 宽无横向滚动，按钮可点 |
| 晚上 | 做一套阅读/听力，或写一篇作文并用键盘作答、自评 | 有判分/范文/自评，进度被记录 |
| 考前 3 天 | 只复习到期词 + 错题 + 作文翻译模板 | 不再推新词 |
| 换电脑 | 在设置里填同步码，从云端恢复 | 进度、错题、自评记录完整回来 |
| 分享给同学 | 发整个目录 zip 或 `studyhub-single.html` | 对方双击即可用，数据各自独立 |

## 3. 范围与优先级

### Must（已交付）

- 26 天逐日计划（11/23–12/18 学习，12/19 考试；最后 3 天只复习）。
- 196 个高频词：闪卡、拼写检测、打字默写、SRS。
- 作文/翻译冲刺库 223 条：句型、模板、词块、高频词、救命短语。
- 听力 4 套（25 句 MP3）、阅读 3 套（15 题）、写作 4 篇、翻译 4 篇。
- 写译作答：大 textarea、词数/字符统计、草稿自动保存、计时、范文与自评。
- 本地保存 + 服务端 SQLite + 历史版本 + 自动备份 + JSON 导入导出。
- 设置页意见反馈：Supabase/SQLite 入库，失败本机待发，可复制。
- 单文件打包，可静态托管。

### Should（已交付，需持续验证）

- 同步冲突处理（409 / 本地覆盖 / 云端恢复）。
- 跨浏览器听力：不再依赖 `speechSynthesis`，改为 MP3 `<audio>`。
- 全项目语法检查、服务端测试、浏览器冒烟。

### Could（后续）

- PWA 离线安装与桌面图标。
- 更多仿真卷/历年真题（需合法来源）。
- 作文 OCR/语法批改（需外部服务）。
- 多设备实时同步（WebSocket/版本向量）。
- 学习数据图表（每日时长、正确率趋势）。

### Won't（本期不做）

- 用户注册、付费、社交。
- 公网多租户 SaaS。
- 自动抓取网络真题。

## 4. 26 天排期设计

| 阶段 | 日期 | 重点 | 每日量 |
| --- | --- | --- | --- |
| 启动 | 11/23–11/24 | 建计划、熟悉界面、背第一批词 | 10 新词 + 到期复习 |

| 考试 | 12/19 | 考试 | — |

计划由 `assets/js/views/full.js` 的 `dailyNew()` / `scheduleGrid()` 按 `examDate` 动态计算；改考试日期后自动重排。

## 6. 成功指标

### 功能指标

- 今日任务 0 配置：打开即见“新词 N / 复习 N / 练习 1”。
- 词汇：四级/六级各 196 个词，全部可背、可拼、可打字默写。
- 写译：四级/六级各 8 道题，均有题目、范文/参考译文、关键点、计时、自评。
- 听力：四级 25 句、六级 27 句，均可逐句播放，不依赖系统语音包。
- 轨道：设置里可切四级/六级；切换后进度互不覆盖；目标日期最多 26 天可完整排期。
- 数据：刷新/重启浏览器后进度仍在；服务端重启后 SQLite 仍在；导出 JSON 可再导入。

### 工程指标

- `npm.cmd test`：4/4 通过。
- `npm.cmd run check`：所有 JS 通过 `node --check`。
- `npm.cmd start` 后 `GET /api/health` 返回 200。
- `file://` 与 `http://127.0.0.1:8787` 两种入口均可完成一次背词/检测。
- 390px 宽无横向溢出。

### 学习效果指标（用户侧，非代码）

- 每天完成今日任务 ≥ 80%。
- 考前 196 词至少过 3 轮；作文模板能默写 3 套；翻译句型能套用 10 句。
- 错题本重复错词 ≤ 20%。

## 7. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 时间只剩 26 天 | 背不完 | 只保留高频；最后 3 天只复习；今日任务上限可调 |
| 数据丢失 | 进度归零 | localStorage + SQLite + 每日备份 + JSON 导出 |
| 单文件托管无目录 | 无法加载外部 JS | 全量内联；移除 sync.js；单文件仅本地保存 |
| 浏览器语音包缺失 | 听力没声音 | 改 edge-tts MP3，内联 data URI |
| 同步码泄露 | 别人可读写进度 | 同步码当密码；服务端只监听本机；公网加 HTTPS/反代 |
| 内容准确性 | 学到错表达 | 以 PDF 高频库为主；仿真题标注“仿真”；范文可替换 |
| 公网服务不可用 | 打不开 | 保留本地 `index.html` 与单文件两个离线入口 |
